# 🌸 Bego Fit — Planes de Nutrición & Entrenamiento

Aplicación web progresiva (PWA) para seguimiento personalizado de
entrenamiento de fuerza y nutrición. Diseñada para usar desde el móvil
como acceso directo en pantalla de inicio.

## 📱 Acceso rápido

| App | URL |
|-----|-----|
| 🏠 Inicio | `index.html` |
| 🏋️ Plan de Fuerza Junio 2026 | `plan_fuerza_junio2026.html` |
| 🍽️ Plan Nutricional Junio 2026 | `plan_nutricion_junio2026.html` |
| 📓 Diario de Entrenamiento | `diario_entrenamiento.html` |

## ✨ Funcionalidades

- **Plan de fuerza mensual** con 4 semanas de progresión, ejercicios
  por día, cargas orientativas y protocolo de fisioterapia integrado
- **Plan nutricional** con ciclo de carbohidratos (Alto / Medio / Bajo),
  macros por día, suplementación y progresión calórica semanal
- **Diario de entrenamiento** con registro de sesiones, pesos por serie,
  récords personales (PRs) y estadísticas
- **Modo Gym** optimizado para móvil — sin necesidad de conexión una vez
  cargado
- Historial de planes anteriores accesible desde el hub principal
